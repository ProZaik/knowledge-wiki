# Инструкция по деплою и обслуживанию Knowledge Wiki на Production

В этом документе описана архитектура деплоя проекта `knowledge-wiki`, параметры боевого сервера и команды для обслуживания системы.

---

## 🏗️ Архитектура деплоя

Проект развернут на VPS со следующими параметрами:
*   **Хост:** `155.212.208.14` (Домен: `wiki.domosrez.ru`)
*   **Пользователь:** `root`
*   **Авторизация:** Настроен беспарольный доступ по SSH-ключам (публичный ключ вашего локального компьютера прописан в `/root/.ssh/authorized_keys`).

### Директории и файлы на сервере:

| Компонент | Путь на сервере | Описание |
|---|---|---|
| **Рабочая папка** | `/var/www/wiki.domosrez.ru` | Содержит файлы веб-сайта Docsify и скрипты MCP-сервера. |
| **Виртуальное окружение** | `/var/www/wiki.domosrez.ru/venv` | Изолированное окружение Python 3 с установленными библиотеками. |

| **Служба Systemd** | `/etc/systemd/system/mcp-wiki.service` | Управляет фоновой работой MCP-сервера. |
| **Конфигурация Nginx** | `/etc/nginx/sites-available/wiki.domosrez.ru.conf` | Раздает Docsify и проксирует `/sse` / `/messages`. |

## 🔄 Процесс автоматического деплоя (Git Push)

Деплой настроен через стандартный механизм Git-хуков (`post-receive`). 

### Как опубликовать изменения:
1. Внесите изменения локально и сделайте коммит.
2. Отправьте ветку `main` в удаленный репозиторий `production`:
   ```bash
   git push production main
   ```

### Что происходит под капотом при пуше:
1. Git распаковывает файлы в `/var/www/wiki.domosrez.ru`.
2. Автоматически обновляются Python-зависимости, если изменился `requirements.txt`.
3. Запускается внутренний линтер `scripts/wiki_lint.py` для проверки ссылок и тегов.
4. Служба `mcp-wiki.service` автоматически перезапускается для применения обновленного кода.

## 🛠️ Команды обслуживания на сервере

Для управления и диагностики зайдите на сервер по SSH (`ssh root@155.212.208.14` или `ssh root@wiki.domosrez.ru`) и используйте следующие команды:

### 1. Управление фоновым MCP-сервером (Systemd)

*   **Проверить статус работы (работает ли бэкенд):**
    ```bash
    systemctl status mcp-wiki.service
    ```
*   **Просмотреть лог ошибок/вывода в реальном времени (логирование):**
    ```bash
    journalctl -u mcp-wiki.service -f
    ```
*   **Перезапустить бэкенд вручную:**
    ```bash
    systemctl restart mcp-wiki.service
    ```
*   **Остановить бэкенд:**
    ```bash
    systemctl stop mcp-wiki.service
    ```

### 2. Веб-сервер Nginx

*   **Проверить синтаксис конфигурации на ошибки:**
    ```bash
    nginx -t
    ```
*   **Перезагрузить Nginx без остановки соединений (после правок конфига):**
    ```bash
    systemctl reload nginx
    ```
*   **Полностью перезапустить Nginx:**
    ```bash
    systemctl restart nginx
    ```

### 3. Ручные скрипты диагностики и статистики

Если вам нужно вручную запустить линтинг или пересчет статистики на сервере, перейдите в папку `/var/www/wiki.domosrez.ru` и выполните:

*   **Запуск линтера (поиск битых ссылок и некорректных тегов):**
    ```bash
    ./venv/bin/python scripts/wiki_lint.py
    ```
*   **Обновление статистики и индекса (`INDEX.md`):**
    ```bash
    ./venv/bin/python scripts/wiki_tool.py --update-stats
    ```

## 🔒 Безопасность и SSL-сертификаты (HTTPS)

На домене `wiki.domosrez.ru` настроен бесплатный SSL-сертификат от **Let's Encrypt**. 
*   **Автопродление:** Настроено автоматически через стандартный фоновый таймер certbot в Linux.
*   **Проверка статуса сертификата:**
    ```bash
    certbot certificates
    ```
*   **Тестовый прогон автопродления:**
    ```bash
    certbot renew --dry-run
    ```
