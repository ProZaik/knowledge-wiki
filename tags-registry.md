# Реестр тегов

> ⚠️ **Обязательное правило:** Используй ТОЛЬКО теги из этого списка. Новый тег добавляется ТОЛЬКО в этот файл и затем используется во всей базе. Теги — строго в нижнем регистре, через дефис, без пробелов.

---

## Правовые институты

| Тег | Что означает |
|---|---|
| `ВРИ` | Вид разрешённого использования земельного участка |
| `ГПЗУ` | Градостроительный план земельного участка |
| `ПЗЗ` | Правила землепользования и застройки |
| `КРТ` | Комплексное развитие территорий |
| `красные-линии` | Красные линии в документации по планировке |
| `раздел-участка` | Раздел/объединение земельных участков |
| `аренда-земли` | Аренда земельных участков (публичных и частных) |
| `нецелевое-использование` | Использование ЗУ не по ВРИ |
| `градрегламент` | Градостроительный регламент |
| `охранная-зона` | Охранные зоны объектов |
| `ОКН` | Объекты культурного наследия |
| `компенсация` | Компенсация при ограничении прав |
| `ЕГРН` | Единый государственный реестр недвижимости |
| `кадастр` | Кадастровый учёт |
| `ИЖС` | Индивидуальное жилищное строительство |
| `единственное-жильё` | Исполнительский иммунитет единственного жилья |
| `банкротство` | Процедуры банкротства и взыскание |
| `взыскание` | Взыскание долгов, исполнительное производство |
| `реконструкция` | Реконструкция объектов капитального строительства (п. 14 ст. 1 ГрК РФ) |
| `самовольное-строительство` | Самовольная постройка и её последствия (ст. 222 ГК РФ) |
