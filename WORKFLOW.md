# Workflow — Как добавлять знания

## Сценарий 1: Быстрая заметка

Ты кидаешь текст или идею → AI создаёт файл в `topics/<тема>/<название>.md`

## Сценарий 2: Источник с материалом

Ты кидаешь ссылку или текст из источника → AI:
1. Создаёт карточку источника в `sources/`
2. Создаёт заметку в `topics/`
3. Связывает их между собой

## Сценарий 3: Необработанное

Если нужно просто сохранить «на потом» → файл идёт в `inbox/` со статусом `draft`

## Сценарий 4: Обновление существующей заметки

Ты говоришь «добавь это к теме X» → AI находит файл и обновляет его

---

## Структура папок

```
knowledge-wiki/
├── topics/
│   ├── <тема-1>/
│   │   ├── _index.md       ← обзор темы
│   │   └── <заметка>.md
│   └── <тема-2>/
├── sources/
│   └── <источник>.md
├── inbox/
│   └── <черновик>.md
└── templates/
    ├── note.md
    ├── source.md
    └── topic-index.md
```

## Статусы заметок

- `draft` — необработанное, сырой материал
- `verified` — проверено и структурировано
- `archived` — устарело, но сохраняется
