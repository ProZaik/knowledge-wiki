# Дом, который... — OSINT-кейс

**Источник:** [gitbook.osint-mindset.com/cases/dom-kotoryi](https://gitbook.osint-mindset.com/cases/dom-kotoryi)  
**Тип:** Обучающий кейс по OSINT (разведка по открытым источникам)

## Аннотация

Кейс из обучающего GitBook по OSINT, посвящённый исследованию объекта недвижимости с использованием открытых источников. Предположительно охватывает:
- методы проверки истории объекта недвижимости
- использование открытых реестров (ЕГРН, кадастровая карта, архивы)
- выявление несоответствий в документации на дом/участок

**Актуальность для задач:** проверка «юридической чистоты» объекта, выявление незарегистрированных построек, анализ собственников.
