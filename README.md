# Knowledge Wiki

Персональная база знаний. Информация из разных источников, структурированная и обработанная.

---

## Навигация

| Раздел | Описание |
|---|---|
| [📁 topics/](topics/) | Заметки по темам |
| [📁 sources/](sources/) | Реестр источников |
| [📁 inbox/](inbox/) | Необработанные материалы |
| [📁 templates/](templates/) | Шаблоны для заметок |
| [📄 INDEX.md](INDEX.md) | Полный индекс всех заметок |
| [📄 DEPLOY.md](DEPLOY.md) | Инструкция по деплою и обслуживанию на продакшене |

---

## Как это работает

1. Ты кидаешь информацию (текст, ссылку, файл, идею)
2. AI обрабатывает → структурирует → записывает в нужный раздел
3. Wiki-движок отображает всё содержимое

## Локальный запуск и MCP-сервер

Для удобства локальной работы, просмотра базы знаний и её полной интеграции с ИИ-моделями (Claude Desktop, Cursor, Perplexity) в проекте настроена автоматическая среда.

### Быстрый старт (Windows)
Просто запустите файл `start_env.bat` в корне проекта. Он автоматически поднимет:
1. **Локальную вики Docsify** на порту `http://localhost:3000` (и откроет её в браузере).
2. **Локальный MCP-сервер (SSE)** на порту `http://localhost:8000/sse` для внешних интеграций.

---

### 1. Веб-интерфейс (Docsify)
Локальный просмотр вики осуществляется без необходимости сборки или Node.js. Запуск через Python:
```bash
python scripts/serve_wiki.py
```
Вики будет доступна по адресу `http://localhost:3000`. Поиск по вики и ссылки работают динамически.

---

### 2. Подключение ИИ-моделей через MCP-сервер

MCP (Model Context Protocol) — открытый стандарт от Anthropic, позволяющий ИИ-моделям безопасно читать файлы вашей базы знаний, искать информацию, импортировать новые источники и автоматически форматировать темы.

#### Доступные инструменты (Tools):
- `get_wiki_stats` — возвращает число файлов, тегов, доменов, проверенных/черновых источников.
- `run_diagnostics` — запускает встроенный линтер и возвращает отчет об ошибках или битых ссылках.
- `search_wiki` — осуществляет мгновенный полнотекстовый поиск по всей базе знаний с выдачей сниппетов.
- `read_file` — считывает содержимое любого markdown-файла базы по относительному пути.
- `ingest_source` — **автоматический импорт нового источника** (Karpathy Ingestion Workflow). ИИ передает полный оригинальный текст, сервер сам создаёт карточку в `sources/`, встраивает ссылки в нужные темы, генерирует записи в `CHANGELOG.md` и пересчитывает статистику.
- `update_topic` — аккуратно обновляет или создает тему в `topics/` с валидацией связей и линтингом.

### 3. Настройка транспорта и подключение клиентов

#### А. Локальное подключение (Claude Desktop / Cursor) — Режим `stdio`
Запускается по умолчанию. Для интеграции добавьте в конфигурационный файл Claude Desktop (`%APPDATA%\Claude\claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "knowledge-wiki": {
      "command": "python",
      "args": [
        "D:\\04_Code_Workspace\\1\\knowledge-wiki\\scripts\\mcp_server.py",
        "--transport",
        "stdio"
      ]
    }
  }
}
```

#### Б. Удаленное подключение (Perplexity / Облачные агенты) — Режим `SSE`
Запустите сервер на порту 8000:
```bash
python scripts/mcp_server.py --transport sse --port 8000
```
Для проброса сервера в интернет (например, для тестов в Perplexity) используйте `ngrok`:
1. Запустите: `ngrok http 8000`
2. Скопируйте полученную ссылку (например, `https://xxxx.ngrok-free.app`)
3. Пропишите её в облачного ИИ-ассистента как SSE-эндпоинт: `https://xxxx.ngrok-free.app/sse`

При развертывании на постоянном сервере с субдоменом и SSL, укажите адрес: `https://mcp.yourdomain.com/sse`.
