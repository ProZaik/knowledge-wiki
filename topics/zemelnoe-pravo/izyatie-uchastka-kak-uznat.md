# Изъятие для госнужд — как узнать о планируемом изъятии участка

> Универсального сайта или реестра решений об изъятии **не существует**. Информация разрознена по нескольким источникам и нуждается в проактивном мониторинге.

## С чего начинается процедура изъятия

Как правило, процедура начинается с **утверждения документации по планировке территории** (ППТ / ПМТ), предусматривающей размещение объектов транспорта, энергетики, коммунального хозяйства и т.д. Данная документация должна быть опубликована на официальном сайте муниципалитета.

## Где искать информацию

| Источник | Что смотреть |
|---|---|
| **Документация ППТ / ПМТ** | Входит ли участок в проект; планируется ли изъятие. Опубликовано на сайте муниципалитета |
| **Генеральный план / ПЗЗ** | Запроектированы ли на участке объекты инфраструктуры |
| **Проект решения КРТ** | При изъятии в рамках комплексного развития территории — из ПЗЗ и/или проекта решения КРТ |
| **Сообщение об изъятии** | Опубликовывается после утверждения ППТ/ПМТ на сайте муниципалитета (в Москве — на сайте ДГИ) |
| **Портал ГИС ОГД** | Для Москвы |
| **Геопортал Подмосковья** | Для Московской области |

## Уведомление правообладателя: порядок

1. Утверждение и опубликование **документации по планировке**
2. Публикация **сообщения о планируемом изъятии** на сайте муниципалитета → заинтересованные лица вправе **в течение 60 дней** ознакомиться со схемой и подать заявление об учёте прав
3. Затем уполномоченный орган **принимает решение об изъятии** и уведомляет правообладателя

## Основания для оспаривания

### Срок действия ППТ — 6 лет

У органа власти есть **6 лет** со дня утверждения ППТ на то, чтобы приступить к строительству публичного объекта. Если срок пропущен — зона размещения **утрачивает силу** и изъятие становится незаконным.

### Отсутствие альтернативного размещения

Закон не допускает произвольного отображения красных линий с наложением на частные территории. **Обязательное условие** изъятия: отсутствие иных вариантов размещения объекта. Если с технической точки зрения другое размещение возможно — основание для оспаривания.

## Минимизация потерь при невозможности оспорить

Если изъятие законно, основная задача — максимизировать **размер возмещения**. Оценка уполномоченного органа, как правило, занижает рыночную стоимость.

Меры, которые нужно принять **до принятия решения об изъятии**:

- Подготовить **внесудебные отчёты об оценке** изъятого имущества
- В ряде случаев целесообразно заранее **сменить ВРИ земли** на более «дорогой»
- Произвести расчёт и документальное обоснование **убытков**, включая упущенную выгоду
- Заключить хозяйственные договоры с компенсацией за **досрочное расторжение**
- Урегулировать **проблемные объекты** (незарегистрированные права, отсутствие долгосрочного договора аренды земли)

> ⚠️ Размер убытков нередко превышает совокупную кадастровую стоимость изъятываемой недвижимости.

## Схема: этапы процедуры изъятия

```
Утверждение документации по планировке территории (ППТ/ПМТ)
                  ↓
Публикация сообщения о планируемом изъятии на сайте ОМСУ
                  ↓
60 дней: ознакомление, подача заявления об учёте прав
                  ↓
Решение об изъятии → уведомление правообладателя
                  ↓
Предложение / подписание соглашения об изъятии
                  ↓
Принудительное изъятие через суд (при несогласии)
```
