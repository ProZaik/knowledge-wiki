# Пристройка vs Отдельное здание с общей стеной

> Сравнительная таблица критериев квалификации объекта как **пристройки в рамках реконструкции** или **отдельного здания с общей стеной**.
> Частные случаи конкретного объекта в таблицу не включены — только нормативные признаки.

**Теги:** #строительство #реконструкция #градостроительство #ГрКРФ #кадастр #согласования

---

## Правовая природа объекта

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Правовая квалификация работ | Реконструкция существующего объекта (п. 14 ст. 1 ГрК РФ) | Новое строительство самостоятельного объекта |
| Изменение параметров исходного объекта | ДА — изменение площади, объёма, высоты основного здания | НЕТ — не изменяет параметры соседнего здания |
| Сохранение правовой идентичности | ДА — основной объект сохраняет правовую идентичность | НЕТ — создаётся новый самостоятельный объект недвижимости |
| Основание для выдачи разрешения | Разрешение на реконструкцию (ст. 51 ГрК РФ) | Разрешение на строительство нового объекта (ст. 51 ГрК РФ) |
| Соответствие ГрК РФ | Соответствует определению реконструкции ГрК РФ | Соответствует определению строительства ГрК РФ |

## Конструктивные критерии

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Характер связи фундаментов | Конструктивно связанный или общий фундамент | Собственный независимый фундамент |
| Несущие конструкции | Использует / опирается на несущие конструкции основного здания | Собственная система несущих конструкций |
| Наружные стены | Общая стена является несущей или связующей конструкцией | Общая стена без конструктивной связи (только ограждающая) |
| Кровельная система | Общая или связанная кровельная система | Собственная независимая кровля |
| Статическая независимость | НЕТ — не может функционировать независимо от основного здания | ДА — может существовать и функционировать независимо |
| Возможность автономного функционирования | НЕТ — требует основное здание для структурной целостности | ДА — полная автономность от соседнего здания |

## Землепользование

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Земельный участок | Использует участок основного здания | Собственный участок или право пользования смежным |
| Отступы от границ | В пределах участка основного здания | Соблюдение нормативных отступов (обычно 0,5–3 м от границ) |
| ГПЗУ | Может потребоваться корректировка ГПЗУ | ОБЯЗАТЕЛЬНО получение ГПЗУ для нового строительства |
| Территориальное зонирование | Должна соответствовать зонированию участка | Должно соответствовать зонированию территории |
| Красные линии | Соблюдение отступов в рамках существующего размещения | Соблюдение отступов от красных линий согласно местным нормам |

## Функциональные характеристики

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Целевое назначение | Должно соответствовать назначению основного здания | Может иметь любое допустимое назначение независимо от соседних |
| Режим эксплуатации | Единый режим эксплуатации с основным зданием | Независимый режим эксплуатации |
| Доступность помещений | Доступ через основное здание или общие зоны | Отдельные входы и доступы |
| Общие входы/выходы | Как правило, общие входы с основным зданием | ОБЯЗАТЕЛЬНО отдельные входы |

## Экспертные заключения

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Строительно-техническая экспертиза | ОБЯЗАТЕЛЬНА при затрагивании несущих конструкций | При необходимости для подтверждения безопасности |
| Обследование конструкций | Оценка влияния на существующие конструкции основного здания | Оценка собственных конструкций без связи с соседними |
| Оценка безопасности | Подтверждение безопасности объединения конструкций | Подтверждение отсутствия негативного влияния на соседние объекты |
| Заключение о конструктивной связи | Документирование конструктивной связи с основным зданием | Документирование отсутствия конструктивной связи |

## Правовые риски

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Самовольное строительство | При отсутствии разрешения на реконструкцию — ст. 222 ГК РФ | При отсутствии разрешения на строительство — ст. 222 ГК РФ |
| Нарушение согласований | Нарушение процедур реконструкции | Нарушение процедур нового строительства |
| Возможность сноса | Возможен снос только пристроенной части (при техвозможности) | Снос всего здания при признании самовольным |
| Штрафные санкции | КоАП РФ — штрафы за самовольную реконструкцию | КоАП РФ — штрафы за самовольное строительство |

## Кадастровый учёт

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Способ постановки на учёт | Изменение характеристик существующего объекта | Постановка на учёт как нового объекта недвижимости |
| Кадастровый номер | Сохраняется номер основного здания | Присваивается новый кадастровый номер |
| Технический план | Техплан с обновлёнными характеристиками основного здания | Техплан нового объекта недвижимости |
| Обновление ЕГРН | Обновление параметров существующего объекта | Внесение нового объекта в ЕГРН |
| Кадастровая стоимость | Пересчёт с учётом увеличенной площади/объёма | Определяется индивидуально для нового объекта |

## Процедуры согласования

| Критерий | Пристройка (реконструкция) | Отдельное здание |
|---|---|---|
| Тип разрешения | Разрешение на реконструкцию | Разрешение на строительство |
| Проектная документация | Проект реконструкции с пристройкой | Проект нового строительства |
| Государственная экспертиза | ОБЯЗАТЕЛЬНА для объектов, требующих экспертизы | При необходимости согласно требованиям ГрК РФ |
| Согласие правообладателей | ОБЯЗАТЕЛЬНО согласие всех собственников нежилого здания | НЕ требуется согласие собственников соседних зданий |
| Техническое заключение | Обязательно для оценки влияния на основные конструкции | При необходимости для подтверждения отсутствия влияния |
| Ввод в эксплуатацию | Как реконструированный объект | Как новый объект капитального строительства |
